# Campus Customs Shop

Yale-blue storefront for **Campus Customs** with **"Ask Dan,"** a PydanticAI shopping assistant (FastAPI + React/Vite), built for AI Foundations HW 4.

All of the code is in [`hw4/`](hw4/). Start with **[`hw4/README.md`](hw4/README.md)**. It covers how to place the data pack (not included in this repo), set up `.env` from `.env.example`, and run the backend and frontend.

- Agent: [`hw4/backend/prompts/prompt.md`](hw4/backend/prompts/prompt.md), [`agent.py`](hw4/backend/agent.py), [`tools.py`](hw4/backend/tools.py), [`models.py`](hw4/backend/models.py)
- How it works: [`hw4/output/harness.md`](hw4/output/harness.md)
- Live test report: [`hw4/output/app_check.html`](hw4/output/app_check.html)
